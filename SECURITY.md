# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates.

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes |
| Older Versions | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested fix (if available).

Do **not** create a public GitHub issue for security vulnerabilities, as this may expose users to unnecessary risk.

Instead, contact the project maintainer privately through GitHub or another available communication channel.

---

## Response Process

After receiving a vulnerability report, we will:

1. Acknowledge the report within **3–5 business days**.
2. Investigate and validate the issue.
3. Develop and test a fix.
4. Release a security update if necessary.
5. Notify the reporter once the issue has been resolved.

---

## Responsible Disclosure

Please provide us with reasonable time to investigate and resolve the issue before publicly disclosing any vulnerability.

We appreciate responsible disclosure and thank security researchers for helping improve this project.

---

## Security Best Practices

To help keep this project secure:

- Always use the latest version.
- Keep dependencies updated.
- Avoid exposing sensitive credentials.
- Follow secure coding practices.
- Report any suspected security issues promptly.

---

## Contact

For security-related concerns, please contact the project maintainer through GitHub.

Thank you for helping keep this project secure.
